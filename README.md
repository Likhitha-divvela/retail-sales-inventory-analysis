📌 Project Overview

This project explores retail sales and inventory data to evaluate business performance, identify product and store trends, and uncover potential inventory risks.

Using SQL Server, Python (Pandas), and Power BI, this project follows a data analytics workflow—from data verification and quality checks to exploratory analysis and interactive dashboard development.

🎯 Goal: Transform raw retail data into meaningful insights that can support data-driven business decisions.

🛠️ Tools & Technologies

Tool| Purpose
🗄️ SQL Server| Data verification, quality checks, and business analysis
🐍 Python| Data exploration and analysis
🐼 Pandas| Data cleaning, transformation, and analytical operations
📊 Power BI| Interactive dashboards, KPIs, and visual reporting
📈 Data Visualization| Communicating trends and business insights

🎯 Project Objectives

- 💰 Analyze sales, revenue, profit, and profitability trends.
- 🏆 Identify top-performing and low-performing products.
- 🏬 Compare sales and profitability across stores.
- 📦 Evaluate inventory value and stock availability.
- ⚠️ Identify out-of-stock and negative-stock records.
- ↩️ Examine product returns and return-rate trends.
- 📊 Present business performance through interactive dashboards.

🔄 Project Workflow

1. 🗄️ SQL Analysis — Verify data, check data quality, and perform business analysis.
2. 🐍 Pandas Analysis — Explore, clean, transform, and analyze data using Python.
3. 📊 Power BI Development — Build interactive reports with KPIs, trends, and comparisons.
4. 💡 Business Insights — Use analytical findings to understand retail performance and inventory risks.
